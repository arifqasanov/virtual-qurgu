01 · Anlayış və tarixçə

Virtual maşın nədir?

Virtual maşın (VM) fiziki kompüterin CPU, RAM, disk və şəbəkə resurslarından istifadə edən, proqram səviyyəsində yaradılmış tam kompüterdir. Öz əməliyyat sistemi, disk faylı və şəbəkə kartı olur. Sağdakı şəkildə qatlar ayrılıb göstərilir.

04 · Yaradılma addımları

VM yaratmaq: 6 addım

  1. Yoxla. BIOS / UEFI-də VT-x və ya AMD-V aktiv olsun.
  2. ISO. OS-in rəsmi ISO obrazını yüklə.
  3. VM yarat. Ad, OS növü, RAM və CPU seç.
  4. Disk. Virtual disk yarat (dinamik ölçü).
  5. Quraş. ISO-nu qoşub OS-i quraşdır.
  6. Tools. Guest Additions, snapshot.

05 · İstifadə və şəbəkə rejimləri

Praktikada istifadə

  1. Bulud. AWS EC2, Azure VM, Google Compute Engine VM-lər üzərində qurulub.
  2. Test. Proqramı fərqli OS-lərdə sistemə zərər vermədən sına.
  3. Təhlükəsizlik. Şübhəli faylı sandbox-da analiz et, pentest laboratoriyası.
  4. Təhsil. Linux, şəbəkə və server təcrübəsi üçün risksiz mühit.
  5. Köhnə sistemlər. Köhnə OS tələb edən tətbiqləri işlət.

Nəticə

Bir cihaz,çox mühit.

  1. VM fiziki resursları bölüşdürərək izolyasiya olunmuş kompüterlər yaradır.
  2. Tip 1 serverlər, Tip 2 test və təhsil üçün daha münasibdir.
  3. Snapshot, klonlama və şəbəkə rejimləri işi təhlükəsiz və çevik edir.
